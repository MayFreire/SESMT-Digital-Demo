# Segurança da demonstração pública

Este projeto não aceita dados pessoais nem se conecta a infraestrutura privada. É um exemplo de interface, não um sistema operacional. Não publique logs, cópias de banco, arquivos .env, credenciais ou dados reais neste repositório. Não reutilize o histórico Git do sistema privado.

Para relatar uma falha na demonstração, contate a autora pelos canais públicos associados ao perfil do repositório, sem publicar segredos em issues.
