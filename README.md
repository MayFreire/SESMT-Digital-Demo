## ✨ Sobre o projeto

O **SESMT Digital** é um projeto de gestão de Saúde e Segurança do Trabalho voltado a simplificar rotinas de inspeção, acompanhamento de riscos e controle de Equipamentos de Proteção Individual (EPIs).

Este repositório apresenta uma **demonstração pública e independente**, criada para o portfólio profissional de **Mayane Freire, Analista de Sistemas**. Seu objetivo é mostrar a experiência de navegação e fluxos de interface, sem expor códigos ou configurações da implementação privada.

## 🧭 O que você pode experimentar

| --- | --- |

| 👥 Equipe | Consultar perfis de profissionais fictícios |
| 📱 Interface responsiva | Navegação em computador e celular |

> **Importante:** as alterações são mantidas apenas na memória da página e desaparecem ao recarregar. Esta demonstração **não representa o funcionamento completo do sistema privado**.

## 🖥️ Como executar

Não há dependências para instalar. Basta abrir o arquivo `index.html` no navegador ou hospedar a pasta como site estático.

```bash
git clone https://github.com/MayFreire/SESMT-Digital-Demo.git
cd SESMT-Digital-Demo
```

Depois, abra `index.html`. Não é necessário Node.js, PostgreSQL, API, login ou arquivos `.env`.

## 🛠️ Tecnologias

- **HTML5** para estrutura e formulários acessíveis.
- **CSS3** para layout responsivo, componentes e identidade visual.
- **JavaScript puro** para navegação, formulários e dados demonstrativos em memória.

## 🔒 Segurança e privacidade

Esta edição foi desenvolvida separadamente e **não importa o código do backend privado, seu histórico Git ou arquivos operacionais**.

- Sem credenciais, tokens, certificados ou configurações internas de infraestrutura.
- Sem comunicação com banco de dados, API privada ou serviços de autenticação.
- Sem dados reais de trabalhadores, fotos de inspeções ou assinaturas.
- Sem persistência de registros: os dados simulados ficam na memória da aba.

**Não utilize esta demonstração em produção nem insira informações pessoais ou operacionais reais.** Consulte também [SECURITY.md](SECURITY.md).
