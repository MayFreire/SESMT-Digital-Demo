Sobre o SESMT Digital

Projeto de portfólio de Mayane Freire, Analista de Sistemas, com foco em experiência do usuário e rotinas digitais de Segurança e Saúde no Trabalho.

A versão profissional privada possui arquitetura própria. Este repositório é uma demonstração visual independente: não inclui o servidor original, algoritmos internos de segurança, configuração de infraestrutura, credenciais ou dados operacionais.

Tecnologias desta demonstração

HTML, CSS e JavaScript. Funciona como site estático sem dependências externas.

Limitações intencionais

Sem login, banco central, sincronização com PostgreSQL, captura de assinaturas, upload de fotos ou tratamento de dados pessoais. Todos os dados demonstrativos permanecem apenas em memória.
